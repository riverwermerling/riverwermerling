# French Drill

A spaced-repetition app for drilling **French verbs, tenses and vocabulary**, with push reminders on your phone.
It is an installable web app (PWA). No build step, no framework: open the files, host the folder.

- **~100 verbs × 8 tenses**, generated by a tested conjugation engine (irregulars, reflexives, être/avoir, agreement, stem-changes)
- **You type everything.** No multiple choice. Mistakes are fixed by retyping the right form, then the card comes back
- **Spaced repetition** tuned for drilling (two passes on day one, then 1 → 3 → 7 → … days), plus a "Max drill" intensity
- **Blitz mode**: timed single forms inside a sentence ("Demain, nous ______ (aller)"), aimed at your weak spots
- **Study guides** for every tense: how it's built, when to use it, the traps
- **Push notifications** morning and evening, only when cards are due or your streak needs saving
- **Works offline**, works as a guest, syncs across devices through **Supabase** when you sign in

## 1. Try it locally (2 minutes)

```bash
cd french-drill
npm run serve        # http://localhost:4173
npm test             # 32 tests (the browser test is skipped unless Playwright is installed)
```

Without Supabase configured the app runs in **guest mode**: everything works and is saved in your browser; there is just no sync and no push.

## 2. Supabase (sync + reminders)

1. **Create a project** at supabase.com (free tier is plenty).
2. **Create the tables:** Dashboard → SQL Editor → paste `supabase/migrations/20261011000000_french_drill.sql` → Run. (Safe to re-run.)
3. **Auth:** Authentication → Providers → Email is on by default. For a personal app, switch off *Confirm email* so sign-up is instant. Under URL Configuration set **Site URL** to wherever you host the app (step 4).
4. **Connect the app:** Project Settings → API → copy the **Project URL** and the **anon public** key into `config.js`:

   ```js
   window.FRENCH_DRILL_CONFIG = {
     SUPABASE_URL: 'https://xxxx.supabase.co',
     SUPABASE_ANON_KEY: 'eyJ…',
     VAPID_PUBLIC_KEY: '',   // step 3
   };
   ```
   The anon key is public by design; Row Level Security makes every row readable only by its owner (this is tested). **Never put the `service_role` key in `config.js`.**

## 3. Push notifications (the "like freeCodeCamp" part)

Reminders are real Web Push, sent from your Supabase project, so they arrive with the app closed.

```bash
# 1. Generate a VAPID key pair (once)
npx web-push generate-vapid-keys

# 2. Put the PUBLIC key in config.js (VAPID_PUBLIC_KEY), then store the secrets for the function
npm i -g supabase && supabase login && supabase link --project-ref <your-ref>
supabase secrets set VAPID_PUBLIC_KEY=... VAPID_PRIVATE_KEY=... \
  VAPID_SUBJECT=mailto:you@example.com APP_URL=https://<you>.github.io/<repo>/

# 3. Deploy the function (from the french-drill folder)
supabase functions deploy send-reminders
```

Then in the Dashboard: **Database → Extensions → enable `pg_cron` and `pg_net`**, open `supabase/cron.sql`, replace the two placeholders (project URL, service-role key) and run it. That schedules the function every 15 minutes; it checks each user's local time against their reminder times and sends a push only if something is due.

Finally, open the app **on your phone → Settings → Account** (sign in) **→ Reminders → Enable reminders**. Set your times (defaults 08:00 and 19:30) and time zone.

> **iPhone:** web push only works for apps installed to the Home Screen (iOS 16.4+). Open the site in Safari → Share → *Add to Home Screen*, then open it from there and enable reminders.
> **Android/desktop Chrome:** install via the browser menu, or just allow notifications.

Test the pipeline without waiting for the schedule:

```bash
curl -X POST "https://<ref>.supabase.co/functions/v1/send-reminders" \
  -H "Authorization: Bearer <service-role-key>"
# → {"checked":1,"sent":0,"removed":0}   (sent only when a reminder time falls in the current 15-min window)
```
Settings → *Show a test notification* checks that your device accepts notifications at all.

## 4. Host it (HTTPS is required for install + push)

**GitHub Pages (included):** the workflow `.github/workflows/french-drill-pages.yml` tests and publishes the folder.
Repo → Settings → Pages → Source: **GitHub Actions**. Optionally add repository *variables* `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `VAPID_PUBLIC_KEY` and the workflow writes `config.js` for you. It runs on pushes to `main` that touch `french-drill/`, or manually from the Actions tab.
(Pages can serve only one site per repo. If you already publish something else from this repo, use Vercel/Netlify with the root directory set to `french-drill` instead; no build command, output directory `.`.)

## How the learning works

**Cards.** Each verb has a *meaning* card (English → type the infinitive), a *past participle + helper* card, and one *conjugation* card per tense (type all six forms). Vocabulary cards ask for the French with its article. About 1,100 cards in total.

**Order.** Meaning → présent → participle → passé composé → imparfait → futur → conditionnel → subjonctif → impératif → plus-que-parfait, most useful verbs first, vocabulary mixed in. Default 12 new cards a day (Settings).

**A new card:** you see the answer first (and can hear it), then type it from memory straight away.

**Grading** (automatic): all forms right first time = *Good* (and *Easy* if fast on a known card); one wrong or an accent slip = *Hard*; two or more wrong = *Again*. Using the hint caps a card at *Hard*. Any miss forces you to retype the correct form, and *Again* cards reappear four cards later in the same session.

**Schedule:** day 1: today, again ~8 hours later (your evening reminder), then +1 day; after that intervals grow by the card's ease. Lapses cut the interval to 40% and relearn. *Intensity* (Settings) shrinks every growth step: *Drill* ×0.75, *Max drill* ×0.55.

**Blitz** picks (verb, tense, person) from what you've started, weighted towards forms you've missed; a miss pulls that card back into your review queue immediately.

**Accents are enforced** (`mangé` ≠ `mange`) with a one-tap accent bar, and flagged as "mind the accents" rather than just "wrong". Agreement is flexible where French allows it: `allé(e)(s)` accepts allé / allée / allés / allées.

## Customising

- **More verbs:** add a line to `js/verbs.js`. Regular verbs need only infinitive + meaning + example; irregulars list `pres`, `pp`, and any stem overrides (see the header comment). `npm test` fails if a verb produces an empty or malformed form.
- **More vocabulary:** add rows to `js/vocab.js` (nouns include the article).
- **Spot-check a verb** in the app: Learn → Verb library → pick the verb → every tense, with audio.

## Notes and limits

- Conjugations are generated from rules plus the irregular data you can read in `js/verbs.js`, and are covered by tests, but if you ever spot a wrong form, treat it as a bug and fix the data.
- Text-to-speech uses your device's French voice (🔊); quality varies by device.
- Syncing is last-write-wins per card, which is right for one person on several devices.
- Not included yet: passé simple, futur antérieur, conditionnel passé, listening-only cards, negation/pronoun drills.
